# กสิกรรมไร้สารพิษ & สุขภาวะพึ่งตน (React + Vite PWA)

ระบบบันทึกข้อมูลดิจิทัลเพื่อการเรียนรู้และพัฒนาตนเอง ตามแนวทางปรัชญาเศรษฐกิจพอเพียง พัฒนาใหม่ด้วย **React 19**, **TypeScript**, **Vite** และ **Tailwind CSS**

## คุณสมบัติเด่น (Features)
1. **แบบบันทึกบัญชีฟาร์ม (Farm Account Record)**
   - ทะเบียนผู้บันทึก ข้อมูลแปลง และผืนผ้าใบวาดผังแปลง (Interactive Canvas)
   - จัดการแปลงเกษตร และทะเบียนชนิดพืชที่ปลูกแต่ละแปลง
   - บันทึกกิจกรรมแปลง: เตรียมดิน, ให้น้ำ, ปุ๋ยชีวภาพ, และการจัดการศัตรูพืชผสมผสาน (IPM) พร้อมแนบรูปถ่ายกิจกรรม
   - บันทึกการเก็บเกี่ยวผลผลิต และการใช้ประโยชน์ (บริโภคในบ้าน / แบ่งปัน / จำหน่าย)
   - วิเคราะห์ต้นทุน-กำไรสุทธิ และมูลค่าการพึ่งตนเอง
   - ถอดบทเรียน 6 เดือน 4 มิติ (สุขภาพ, เศรษฐกิจ, สังคม, สิ่งแวดล้อม)
   - สรุปสถิติและกราฟแสดงผลผลิตและการเงิน (Chart.js)
   - ส่งออกเอกสารเป็น Microsoft Word (.doc) และ PDF สำหรับส่งงาน

2. **สมุดบันทึกบัญชีสุขภาพ (Holistic Health Record - ยา 9 เม็ด)**
   - ข้อมูลทะเบียนและปัญหาสุขภาพหลัก
   - บันทึกสัญญาณชีพและสุขภาพกายภาพรายเดือน (น้ำหนัก, ความดัน, น้ำตาลในเลือด, รอบเอว, การนอนหลับ)
   - บันทึกการปฏิบัติยา 9 เม็ดรายเดือน พร้อมแนบรูปถ่ายกิจกรรม
   - บันทึกตัวชี้วัดสุขภาพ 3 ประการ (สบาย, เบากาย, มีกำลัง) ระดับคะแนน 1-10
   - ประเมินสุขภาวะองค์รวม 4 ด้าน (จิตใจ, จิตวิญญาณ, สังคม, เศรษฐกิจ)
   - ไดอารี่ถอดบทเรียนรายเดือน (6 เดือนแห่งการเปลี่ยนแปลง)
   - กราฟสถิติเส้นแนวโน้มตัวชี้วัด และเรดาร์สุขภาวะ 4 ด้าน (ก่อนเริ่ม vs เดือนที่ 6)
   - ส่งออกเอกสารเป็น Word (.doc) และ PDF

3. **PWA & Local-First Architecture**
   - ใช้งานได้บนทุกอุปกรณ์ (มือถือ แท็บเล็ต คอมพิวเตอร์)
   - บันทึกข้อมูลอัตโนมัติลงเครื่อง (LocalStorage) ใช้งานออฟไลน์ได้
   - ระบบสำรองและนำเข้าข้อมูล JSON ป้องกันข้อมูลสูญหาย

## คำสั่งสำหรับพัฒนา (Development)
```bash
npm install
npm run dev      # รัน dev server ที่พอร์ต 3000
npm run build    # บิลด์สำหรับการ deploy
npm run lint     # ตรวจสอบ TypeScript syntax และ type safety
```
